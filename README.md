# Wonder Comet desktop

Installers for the Wonder Comet desktop app. Download the latest from
**[wondercomet.com/download](https://wondercomet.com/download)** or the
[releases page](https://github.com/devlabspro/wonder-comet-desktop/releases/latest).

- **Windows:** `WonderComet-Setup.exe`
- **Mac (Apple silicon):** `WonderComet-mac-arm64.dmg`
- **Mac (Intel):** `WonderComet-mac-x64.dmg`

The app updates itself from these releases. This repository holds release
binaries only.
